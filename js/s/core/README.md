# Set Algebra

## Base

| Symbol | Name | Meaning |
|--------|------|---------|
| $\varnothing$ | Empty Set | A set containing no elements |
| $\mathbb{U}$ | Universal Set | The set containing all elements under consideration. Everything is relative to this |
| $\in$	| Element Of | x ∈ A means x is an element of A |
| $\subseteq$	| Subset | A ⊆ B means every element of A is also in B |
| $\subset$ | Proper Subset | A ⊂ B means A is a subset of B but not equal to B |
| $\supseteq$	| Superset | A ⊇ B means A contains B |
| $\supset$ | Proper Superset | A strictly contains B |
| =	| Equal Sets | Same elements, regardless of order |
| $\ne$	| Not Equal | Different elements |
| $\cup$ | Union | A ∪ B means everything in A or B |
| $\cap$ | Intersection | A ∩ B means everything common to both A and B |
| - \ | Difference | A − B means everything in A that is not in B. Sometimes ∖ |
| $\bigtriangleup$ | Symmetric Difference | A △ B means elements in either set but not both |
| $^c$ | Complement | A $^c$ means everything in the Universal Set except A |
| ∣ | Cardinality | ∣A∣ means the number of elements in A |
| $\times$ | Cartesian Product | A $\times$ B means every element of A paired with every element of B.  This results in semantic and topological products  |

## Semantic and Structural/Topological

| Symbol | Name | Meaning |
|--------|------|---------|
| $\cong$ | Structural/isomorphic Equivalence | A ≅ B  means A and B have equivalent structural topology even if their actual values differ (congruent) |
| ≅ₛ | Semantic Equivalence | A ≅ₛ B  means A and B have equivalent semantic topology even if their actual values differ |
| ⋐ | Structural Subset | A ⋐ B means Does A's data topology fits within B's data topology | 
| ⋐ₛ | Semantic Subset | A ⋐ B means Does A's semantic topology fits within B's semantic topology | 
| ⋑ | Structural Superset |  |
| ⋑ₛ | Semantic Superset |  |
| ⋒ | Structural Intersection |  |
| ⋒ₛ | Semantic Intersection |  |
| ⋓ | Structural Union |  |
| ⋓ₛ | Semantic Union |  |
| ⊎ | Multiset Union | Useful to preserve multiplicities because ordinary set algebra throws them away and this is important when polymorphic multi-dimensional sets are unioned.  If multisets do not need to be preserved then ∪ can be used instead. |
